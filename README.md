# Parser2.0

Минимальное безопасное приложение для проверки идеи.

Сейчас приложение:

- берет тестовые сообщения;
- ищет объект, должность, количество людей и пол;
- показывает результат как черновик;
- помечает неясные строки как `требует проверки`;
- ничего не отправляет в Telegram;
- ничего не публикует в `Вектор`.

## Как запустить

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

После запуска открой в браузере:

```text
http://127.0.0.1:5000
```
