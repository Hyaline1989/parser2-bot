# Parser2.0 на Linux-сервере

Эти файлы нужны для тестового запуска Parser2.0 на сервере рядом с Вектором.

Режим безопасный:

- MAX-бот только читает сообщения.
- Parser2.0 только создаёт черновики.
- В Вектор ничего не публикуется.
- В MAX ничего не отправляется.

## Что будет работать

- `parser2-web.service` — веб-интерфейс Parser2.0.
- `parser2-maxbot.service` — слушатель MAX-сообщений.

## Рабочие пути на сервере

- Код приложения: `/opt/parser2`
- Токен и настройки: `/etc/parser2/parser2.env`
- Веб-интерфейс локально: `127.0.0.1:5010`

## Важно

Токен MAX нельзя хранить в коде. Его нужно положить в `/etc/parser2/parser2.env`.
